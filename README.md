# @amlplugins/langchain-aws

Native `@langchain/aws` SDK re-exported under the `@amlplugins` namespace.

> LangChain AWS provider — ChatBedrockConverse, BedrockEmbeddings, ChatBedrock for Anthropic/Llama/Mistral on Bedrock.

## Install

```bash
npm install @amlplugins/langchain-aws
```

## Use

```ts
import { /* named exports from @langchain/aws */ } from "@amlplugins/langchain-aws";
// or
import sdk from "@amlplugins/langchain-aws";
```

This package additionally re-exports `@langchain/core` under the `secondary` namespace.

Built and published by GitHub Actions on every push to `main`.

Part of the amlplugins family — see https://github.com/amlplugins.
